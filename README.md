# Cold Email Angles: Grow With Khalaf

An Arabic guide to opening a first B2B cold email from one of three angles: Case study, Events, or Resource (lead magnet). Each angle has a full example email to copy, plus a Claude prompt and a pre-send checklist. Companion to the [copy guide](https://mohamedkhalafalla.github.io/gwk-cold-email-copy/) and the [setup guide](https://mohamedkhalafalla.github.io/gwk-cold-email-setup/).

Live page: https://mohamedkhalafalla.github.io/gwk-cold-email-angles/

Names, numbers and events are illustrative. Not affiliated with Anthropic.
